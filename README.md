# らくらく勤怠

少人数チーム向けのスマホ勤怠打刻アプリです。

## GitHub Pages での公開

1. GitHub で新しい **Public** リポジトリ（例: `kintai-app`）を作成します。
2. このフォルダ内のファイルをすべてリポジトリの最上位へアップロードします。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** の **Source** を **Deploy from a branch** にします。
5. Branch に **main**、フォルダに **/(root)** を選び、**Save** を押します。
6. 数分後に表示される `https://<GitHubユーザー名>.github.io/kintai-app/` をスマホのSafariまたはChromeで開きます。

## 注意

- 公開リポジトリは誰でもソースコードを閲覧できます。氏名や勤怠データをファイル内に書き込まないでください。
- 現時点の打刻データは各端末内に保存されます。メンバー間での共有・管理者集計には別途クラウドデータベースが必要です。

## 会社名・管理者の設定

Apps Scriptで `setup` を実行すると、スプレッドシートに「設定」シートが作成されます。次の2行の「値」を編集してください。

| 項目 | 値の例 |
| --- | --- |
| 会社名 | 株式会社サンプル |
| 管理者 | 山田 太郎、佐藤 花子 |
| 締め日 | 20 |
| 残業開始時刻 | 18:00 |

管理者は「メンバー」シートに登録済みの氏名を、読点またはカンマで区切って入力します。管理者として設定された人を選んだときだけ、スマホ画面の「管理・集計」ボタンが表示されます。

締め日が `20` の場合、集計期間は前月21日から当月20日です。残業開始時刻を `18:00` にすると、18時以降を残業時間として集計します。

## 名前の選択

端末での個人認証は行いません。打刻する人の名前を選んで打刻します。最後に選んだ名前は、次回アプリを開いたときにも表示されますが、名前はいつでも変更できます。

## 個人PINと月間勤怠

「自分の1か月分の勤怠を確認」から、選択中の本人が数字3桁の個人PINを初回設定します。2回目以降は同じPINで本人分だけを表示します。PINはスプレッドシートへハッシュ化して保存し、管理者にも元の数字は表示しません。本人が忘れた場合、管理者は管理画面からその人のPINをリセットできます。リセット後は本人が新しい3桁を設定します。

PINが未設定の場合は「個人PINの初回登録」と表示され、入力した3桁が登録されることを画面で案内します。起動データはApps Script側で最大5分間キャッシュし、打刻・設定変更時には自動的にキャッシュを更新します。

## 外出・戻り

勤務途中で抜ける場合は「外出」を押し、戻り予定時刻を入力します。戻ったときに「戻り」を押すと、中抜け時間が記録されます。管理者画面の「中抜け連絡一覧」と変更履歴で確認でき、Excel用CSVにも外出・戻りと戻り予定時刻が出力されます。中抜け時間は勤務時間から差し引かれます。

## 全員の打刻を管理者が集計する設定（Googleスプレッドシート）

1. Google Drive で空のGoogleスプレッドシートを1つ作成し、名前を「勤怠管理」にします。
2. シートのメニューから **拡張機能** → **Apps Script** を開きます。
3. このプロジェクトの `google-apps-script/Code.gs` の内容で、エディタ内のコードをすべて置き換えて保存します。
4. 上部の関数選択で `setup` を選び、**実行**します。Googleの権限確認が出たら、作成したスプレッドシートへのアクセスを許可します。既存データは残したまま、「メンバー」に個人PINハッシュ列、「打刻記録」に戻り予定時刻列が追加されます。
5. **デプロイ** → **新しいデプロイ** → 種類の選択で **ウェブアプリ** を選びます。
6. 「次のユーザーとして実行」は **自分**、「アクセスできるユーザー」は、スタッフがGoogleアカウントなしで打刻する場合は **全員** を選びます。職場のGoogle Workspaceでは、管理者の設定によって選べる項目が異なります。
7. **デプロイ**を押し、権限を許可して、表示されたURL（末尾が `/exec`）をコピーします。
8. `app-config.js` の `window.KINTAI_API_URL = ''` の空欄へ、そのURLを貼り付けて保存します。
9. 更新済みの `app-config.js` を含め、ファイルをGitHub Pagesへ再アップロードします。

以後、すべてのスマホの打刻が同じスプレッドシートの「打刻記録」シートに追加されます。アプリの「管理・集計」からも全員分をCSV形式で出力できます。

### 管理者機能

- 管理者暗証番号を通過した画面だけで、Excel用CSVを出力できます。
- 月を選ぶと、登録者ごとの出勤日数と勤務時間（出勤・直行から退勤・直帰まで）を表示します。
- 管理者は打刻を修正・削除できます。削除は「削除済」として残り、打刻・修正・削除はすべてスプレッドシートの「変更履歴」シートに記録されます。
- 管理者は「現場」を追加・削除（無効化）できます。スタッフは出勤・直行を打刻した後、現場を複数選択でき、その場で新しい現場も追加できます。スタッフによる追加も「変更履歴」に記録され、現場名はExcel出力にも含まれます。
- 2026年の休日は「2026年間カレンダーA4.xlsx」で赤文字になっている87日です。更新後にApps Scriptの `setup` を実行すると、従来の休日を消去して「休日」シートをこの87日に入れ替えます。もう一度手動で入れ替える場合は `replaceHolidaysFromCompanyCalendar2026` を実行します。
- `setup` を実行すると「まとめ編集」シートも作成されます。会社・集計設定、メンバー、現場、休日を黄色セルで編集し、上部メニューの **勤怠管理 → まとめ編集を各シートへ反映** を選ぶと、アプリ用の各シートへまとめて反映されます。個人PINは安全のため表示せず、設定済／未設定だけを表示します。
- 「月別集計」シートには、締め日基準の通常出勤日数・休日出勤日数・通常勤務時間・休日勤務時間・合計勤務時間・残業時間・中抜け時間が表示されます。B2の対象月を `2026-09` の形式で変更すると自動再集計されます。手動更新は **勤怠管理 → 月別集計を更新** です。
- 同じ日には、開始打刻（出勤・直行）のどちらか1件、終了打刻（退勤・直帰）のどちらか1件だけを記録できます。アプリとスプレッドシートの両方で重複を防止します。
- `Code.gs` を更新した場合は、Apps Scriptの **デプロイを管理** から既存のウェブアプリを編集し、新しいバージョンをデプロイしてください。

> 初期管理者暗証番号は `1234` です。最初の設定後にアプリの管理画面から必ず変更してください。

管理者暗証番号を忘れた場合は、Apps Scriptエディタ上部の関数一覧から `resetAdminPin` を選び、**実行**してください。暗証番号が `1234` に戻ります。ログイン後、すぐに新しい暗証番号へ変更してください。
